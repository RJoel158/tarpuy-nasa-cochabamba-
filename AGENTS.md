# Tarpuy Nasa Space Apps — Sistema de Habilidades por Rol

Para mantener la excelencia multidisciplinaria requerida en el hackathon NASA Space Apps, aplicar las siguientes directrices y skills según el área de trabajo:

1. **Diseño UX/UI & Mobile-First**: [Tarpuy UX móvil](skills/tarpuy-mobile-ux/SKILL.md) (accesibilidad, 320-390px, visualización amigable para productores).
2. **Animación, Micro-interacciones & Audio**: [Tarpuy movimiento](skills/tarpuy-motion/SKILL.md) (transiciones fluidas y retroalimentación de voz).
3. **Ciencia y Datos Satelitales**: [Tarpuy Ciencia y Datos](skills/tarpuy-science-data/SKILL.md) (validación NASA POWER, SMAP, GPM, balance hídrico FAO-56 y agronomía).
4. **Ingeniería de Software & Resiliencia Offline**: [Tarpuy Ingeniería Offline](skills/tarpuy-engineering-offline/SKILL.md) (FastAPI, contratos de datos, PWA Service Worker, IndexedDB y robustez de red).
5. **Comunicación, Storytelling & Quechua**: [Tarpuy Comunicación y Storytelling](skills/tarpuy-communication-storytelling/SKILL.md) (narrativa del pitch para jurados y guiones bilingües Quechua/Español).
6. **Emprendimiento, Viabilidad & Impacto**: [Tarpuy Emprendimiento e Impacto](skills/tarpuy-business-impact/SKILL.md) (modelo de sostenibilidad, impacto en pequeños productores y gobernanza).


Para tareas multidisciplinarias, usar las guías según el entregable. Combinar las relevantes cuando una tarea cruce roles.

- [Ingeniería y desarrollo](skills/tarpuy-ingenieria/SKILL.md) para implementar y probar cambios de extremo a extremo.
- [Ciencia de datos y agronomía](skills/tarpuy-evidencia-agricola/SKILL.md) para rastrear evidencia y evaluar rotaciones por zona.
- [Comunicación y pitch](skills/tarpuy-comunicacion/SKILL.md) para explicar el producto a productores, técnicos y jurado.
- [Arte y storytelling](skills/tarpuy-narrativa-visual/SKILL.md) para crear escenas y recursos visuales para contar la demo.
- [Emprendimiento y piloto](skills/tarpuy-piloto/SKILL.md) para diseñar un piloto medible con productores locales.
- [Aprendizaje y primer hackathon](skills/tarpuy-hackathon/SKILL.md) para planear, practicar y cerrar una demo individual.
