# Comunicación y pitch

1. Identificar público, duración y acción esperada. Para productor, empezar por comunidad, situación y próximo paso. Para jurado, explicar el problema de campo, demostrar una decisión y atribuir los datos utilizados.

2. Vincular cada afirmación comprobable con una vista, respuesta de API o medición. Para decir «funciona sin señal», especificar qué se descargó antes y qué puede consultarse. Revisar términos quechuas existentes y marcar frases nuevas para revisión por hablantes locales.

3. Entregar el texto listo para usar con duración estimada y, si es para demo, la acción que acompaña cada frase. Ensayar las preguntas «¿qué aporta NASA?» y «¿qué sabes realmente de esta parcela?».
