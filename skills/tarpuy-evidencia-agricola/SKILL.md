# Ciencia de datos y agronomía

1. Elegir una afirmación concreta, como «esta alternativa encaja mejor con la prioridad de ahorrar agua en Punata». Seguirla desde la pantalla hasta engine/scoring.py, el catálogo de cultivos, la zona y el cliente ETL. Anotar proveedor, variable, unidad, escala, período, fecha de descarga y estado de respaldo.

2. Separar climatología NASA POWER, observaciones recientes, pronóstico Open-Meteo y referencias regionales. Revisar faltantes, denominadores y reutilización de datos antiguos. Identificar dónde se asigna el punto GPS a una zona piloto.

3. Repetir la comparación con una sola variable distinta, como riego o prioridad, y con el mismo paquete offline. Explicar qué regla cambia el orden. Si se discute impacto, diseñar una medición de campo con línea base, unidad, período y comparador. Identificar la pregunta concreta para un agrónomo y los conocimientos locales que faltan.

4. Entregar una tabla de afirmación, evidencia reproducible, alcance y limitación. Etiquetar proyecciones e hipótesis y reservar afirmaciones sobre rendimiento o ahorro real para resultados medidos.
